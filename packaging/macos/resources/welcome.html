Welcome to VidReclaim

Save video space thoughtfully, and stitch mixed clips without wrestling with codec settings.

  • Native Mac interface with file pickers, safety explanations, progress, and ETA
  • Adaptive, sample-tested HEVC compression
  • Side-by-side browser review before long jobs
  • DVD main-content detection that skips trailers and menus
  • Friendly stitching for mixed clips, with chapters and progress
  • Interactive disk-usage treemaps to find the biggest files and folders
  • FFmpeg, HandBrake, Python, and required libraries included

This Apple-silicon package is self-contained. It does not require Homebrew or a separate Python installation.
