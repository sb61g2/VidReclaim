What will be installed

/Applications/VidReclaim.app is a native Mac interface for compression planning and jobs, clip stitching, disk maps, progress, and logs.

/usr/local/bin/vidreclaim provides the command-line tool.

Documentation and an uninstaller are also included. The complete installation uses roughly 100 MB.

Safe defaults

Planning and visual review never modify source videos. Full runs write verified results to a staging folder unless you explicitly choose replacement or rolling deletion. DVD trailers, menus, and extras are excluded by default.

Rolling deletion is irreversible. It requires both --delete-source-as-you-go and --yes.

Compatibility

This build targets Apple-silicon Macs running macOS 26 or later. The bundled codec tools were built against the macOS 26 SDK. The package payload is ad-hoc signed. The installer itself is not Developer ID signed or notarized.
